# 어스본레인져스 (Earthborne Rangers) 보조도구

## 개요
어스본레인져스 보드게임의 캠페인 관리 및 덱 관리를 위한 디지털 보조도구.
공식 캠페인 트래커 시트(PDF) 및 [RangersDB](https://rangersdb.com/) 스타일을 참조하여 구현.
기존 characterSheet(D&D 캐릭터 시트)와 동일한 디자인 시스템(다크 퍼플 테마)을 적용.

## 주요 기능

### 1. 캠페인 트래커 (공식 시트 기반)
- **캠페인 선택**: Lure of the Valley / Legacy of the Ancestors 캠페인별 날씨 패턴 지원
- **Day Track (1-30)**: 각 날짜별 미리 배정된 날씨가 표시되는 수평 트랙 (클릭으로 현재 날짜 설정)
- **Rangers**: 1~4인 레인져 이름 등록
- **Current Position**: Location + Path Terrain 기록
- **Missions**: Day + Name + ◇◇◇ (3단계 다이아몬드 진행도 마커)
- **Rewards**: 자유 텍스트 보상 리스트
- **Notable Events**: 자유 텍스트 사건 기록

### 2. 덱 매니저
- **애스펙트(Aspect) 카드 선택**: 12종 중 택1 (Fitness/Focus/Awareness/Spirit 수치 배분)
- **배경(Background) 선택**: Artisan/Shepherd/Traveler/Forager 중 택1 → 9장 풀에서 5장 선택
- **전문(Specialty) 선택**: 역할(Role) 카드 1장 + 12장 풀에서 5장 선택
- **성격(Personality)**: 각 애스펙트당 1장 선택 (2장 복사 → 8장)
- **외부 관심사(Outside Interest)**: 1장 선택
- **덱 합계**: 30장 목표 카운터 + 진행 바
- **다중 덱**: 레인져별 독립 덱 관리

## 캠페인별 날씨 패턴

### Lure of the Valley (골짜기의 유혹)
- 날씨 유형: A Perfect Day, Downpour, Howling Winds
- Guide Ref: 94.1

### Legacy of the Ancestors (선조의 유산)
- 날씨 유형: Downpour, A Perfect Day, Howling Wind, Enveloping Silence, Glitterain, Shimmering, Runoff
- Guide Ref: 199.2

## 기술 스택
- React (Class Component) + Tailwind CSS
- CSS Custom Properties를 이용한 테마 시스템
- localStorage 기반 세션 자동 저장/복원
- JSON 내보내기/불러오기 지원

## 게임 참조 정보

### 4가지 애스펙트 (Aspect)
| 애스펙트 | 영문 | 설명 | 기본 테스트 |
|---------|------|------|------------|
| 체력 | Fitness | 신체적 활동 | 이동(Traverse) |
| 집중 | Focus | 정밀한 행동 | 기억(Remember) |
| 인지 | Awareness | 주변 관찰 | 회피(Avoid) |
| 정신 | Spirit | 사회적 교류 | 연결(Connect) |

### 배경 (Background) - 코어 세트
- Artisan (장인)
- Shepherd (목자)
- Traveler (여행자)
- Forager (채집가)

### 전문 (Specialty) - 코어 세트
- Explorer (탐험가)
- Shaper (형성자)
- (추가 확장 전문은 향후 업데이트)

- Gear (장비)
- Moment (순간)
- Companion (동반자)
- Attachment (부착물)
- Expert (전문가)
