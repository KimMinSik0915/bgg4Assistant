# 어스본 레인저스 계곡(The Valley) 노드 목록

형식: `[경로 덱] 목적지`  /  ★ = 핵심(pivotal) 장소
길은 양방향이라 같은 길이 양쪽 장소에 한 번씩 나옵니다.
경로 덱 이름은 지도 범례 번역: 고목림(Old-growth), 산길(Mountain Pass), 숲(Woods), 호숫가(Lakeshore), 풀밭(Grassland), 협곡(Ravine), 늪지(Swamp), 강(River, 탈것 필요)
